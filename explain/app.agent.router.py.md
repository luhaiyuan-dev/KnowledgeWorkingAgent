# `app/agent/router.py` 详解

`TaskRouter` 决定任务进入普通对话、知识库、工具或组合路径。用户手动选择模式时直接尊重，不浪费一次 LLM 调用。

自动模式有两层：真实模型存在时调用 `with_structured_output(RouteDecision)`，让路由结果通过 Pydantic 校验；调用失败时回退 `_heuristic_route()`，避免路由服务抖动导致整个应用不可用。启发式先识别计算、联网、Excel、文件读取和文档分析，再识别公司/制度/政策等知识关键词。两类同时存在返回 combo。`_looks_like_calculation()` 同时检查意图词和数字运算式。

规则路由可解释、便宜、确定，但覆盖不了所有表达；模型路由灵活但增加延迟、费用和不确定性。二者组合是工程折中。生产应把误路由样本加入评估集，统计混淆矩阵，并让低置信度问题走安全的知识检索而非高风险工具。
