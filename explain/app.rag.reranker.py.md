# `app/rag/reranker.py` 详解

向量召回追求“不要漏”，重排追求“把最有用的放前面”。`HybridReranker` 把向量分乘 0.7、词面分乘 0.3。精确词面信号能提升产品名、地区、金额和制度编号，而向量分保持一定语义容错。

构造函数验证权重和为 1，防止配置者误解最终分。`rerank()` 为每个候选建立查询/文档 token 集合，计算交集占查询 token 的比例，再合成得分、应用最低阈值、封装 `RetrievedChunk`，最后排序截取 top_n。

`_tokens()` 对去空白中文做双字切片，同时提取英文、数字、下划线和连字符词。双字比单字更有区分度，例如“报销”“审批”；set 会忽略词频，算法简单可解释。`_overlap_score()` 以查询 token 数为分母，回答“查询条件有多少被文档覆盖”。

生产可替换为 BGE reranker 或供应商 rerank API，但要评估额外延迟，并保留原始召回分、重排分和模型版本供诊断。不要只在 LLM 前盲目塞几十个候选，那会增加噪声和费用。
