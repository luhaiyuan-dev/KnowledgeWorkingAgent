# Web 对话界面设计规范

概念图见 `ui-concept.png`。它由 Image Gen 生成，仅作为视觉规范，最终 UI 全部由 Streamlit 和 CSS 原生渲染。

- 结构：左侧会话与身份控制，中间对话，右侧来源与执行轨迹的语义在 Streamlit 中折叠到消息下方，以兼容窄屏。
- 背景：主区域真白 `#FFFFFF`；侧栏冷灰 `#F7F9FC`。
- 文字：主色深海军蓝 `#071B47`；辅助文字 `#66758C`。
- 强调：按钮与来源边线使用 `#2F76E8`，不使用渐变。
- 容器：开放式消息流，来源只用左边线，不堆叠多层卡片。
- 圆角：8—12 px；阴影只用于底部输入框，帮助识别主要操作。
- 响应式：Streamlit 侧栏可折叠，证据跟随答案，避免三列在手机上挤压。
- 控件：所有标题、消息、按钮、模式与来源文字都属于可访问的代码原生文本。
